# LWW-CORE-DNA
A genetic blueprint for web applications consisting of foundational SVGs, semantic web components, design tokens and reusable interface patterns.

## Implementation
The lwt-core script must be included first. Then you can choose which library set to include `lwt-general.js`, `lwt-forms.js` or `lwt-dashboards.js`

```html
<!DOCTYPE html>
    <head>
        <script src="/lwt-core.js" type="text/javascript"></script>
        <script src="/lwt-general.js" type="text/javascript"></script>
    </head>
    <body>
        
        

    </body>
</html>
```
